🔧 pegasus-dl

✕
pegasus-dl by pegasus-ps5
Pegasus DL - Direct package downloading from your PS5, managed through a local web interface. No PC required for transfers.
  • ✅ No PC required for transfer
  • ✅ Works directly from PS5 browser
  • ✅ Compatible with all jailbroken PS5 firmware versions
  • ✅ Multiple download connections with resume support
🎯 How to use
1️⃣ Download pegasus_dl.elf from GitHub releases
2️⃣ Send the payload to your PS5 using your usual payload loader
3️⃣ Open from any device on the same network: http://<your-ps5-ip>:6970/
4️⃣ Choose a writable download folder in Settings
5️⃣ Add a catalog source (JSON file with package links)
6️⃣ Search, select, and queue your downloads
⚠️ Important Notes
• Queue does not survive reboot - downloads are lost if PS5 restarts
• Catalogs not included - you must provide your own catalog sources
• Downloader only - does NOT install packages (use a separate installer)
• Resume support depends on the download host
• Use only with content you own or have permission to download

⚡ exFAT-Ripper

✕
exFAT Ripper by kerrdec97
Premium Windows desktop launcher for the PS5 exFAT library. Browse cover art, PPSA codes, titles, versions and download links — with scraping or library updates running in the background.
  • ✅ Built with pywebview (Python backend + HTML/CSS/JS frontend)
  • ✅ Gaming-launcher UI: custom titlebar, animated sidebar, cover art grid, cinematic detail panel
  • ✅ Offline-safe: after initial scraping, everything works offline
  • ✅ Instant offline link unlocking (AES-GCM decryption)
  • ✅ Linux support (AppImage build) - contributed by Nazky
🎯 Key Features
Interface: DM Sans + JetBrains Mono, dark theme, hover animations, glow effects. 440px wide detail panel with 172px hero image.

Library: Tab-pill (All | Native | Backports | DLCs | Updates) with live counts. Library Health widget (SVG ring gauge) with percentage score. Storage widget (TB used/free).

Cards: 3/4 aspect ratio, FW color coding (green=native, purple=backport, cyan=FW version, amber=DLC). Hover quick-actions overlay (favourite, open folder, re-scrape, fetch metadata). Favourite star (localStorage persistent).

Detail Panel: Metacritic/OpenCritic/HowLongToBeat scores. 2-col metadata grid (Developer, Publisher, Genres, Play Modes, Languages, Release Date). Collapsible description.

Files Tab: Version-grouped download cards (newest first). Older versions collapsible. Host cards with emojis (📦 Akirabox, ⚓ VikingFile, 💾 Datanodes, 🔥 MediaFire). Open + Copy buttons per link, Open All + Copy All for multi-link hosts.

Screenshots: Fullscreen gallery with keyboard navigation (← → Esc), thumbnails, adjacent image preloading.

Settings: RAWG + IGDB API keys, cover cache controls, metadata enrichment toggles, database repair.
🔧 Metadata API Keys
Metadata (descriptions, ratings, genres, Metacritic, screenshots) comes from external APIs. Both have free tiers.
  • RAWG — 20,000 req/month → rawg.io/apidocs
  • IGDB — Unlimited (Twitch auth) → api.igdb.com
⚠️ Important Notes
• First launch of the unsigned .exe may show a Windows SmartScreen warning — "More info" → "Run anyway" (normal for unsigned apps).
• The .exe is large (bundled Chromium + Python runtime). Expected.
• If scraping fails with "grid never appeared", the site is showing a CAPTCHA. Open the site in Brave/Chrome, solve it, leave it open, and scrape again.
• This app scrapes a site hosting pirated content. Make sure your use complies with local laws.

🌈 Spectrum Library

✕
Spectrum Library by Phoenixx1202
Spectrum Library is a lightweight content manager designed to organize and deliver supported game files in a simple, clean, and user-friendly way. It provides a streamlined library interface with categories, cover artwork, file details, download controls, and installation status, making it easier for users to browse available content and manage their downloads from one place.
  • ✅ Lightweight content manager for game files
  • ✅ Clean library interface with categories and cover artwork
  • ✅ File details, download controls, and installation status
  • ✅ Easy browsing and download management from one place
  • 👤 Created by Phoenixx1202
